One fortune cookie message for a software engineer, written as a single
line of at most 120 characters — the funniest one I could write, with the
punchline landing on the last word.

The fortune:

> The bug you cannot reproduce will reproduce itself in front of your manager.

## Run it

```sh
python3 main.py
```

That writes the fortune to `/output/entry.txt`. Check it first without
writing anything:

```sh
python3 main.py --self-test
```
